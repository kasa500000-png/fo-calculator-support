Visco Calculator는 연료유 성적서 값을 이용해 목표 점도별 예상 온도를 계산하는 오프라인 앱입니다.

앱은 개인정보, 계정 정보, 사용 기록, 성적서 입력값을 수집하거나 외부 서버로 전송하지 않습니다. 광고 및 사용자 분석 도구를 사용하지 않습니다. 기존 빌드 1·2의 입력값은 메모리에서만 처리됩니다. 최근 설정 저장과 삭제 방식은 아래 안내를 확인하세요.

사용자가 결과 복사를 선택하면 결과 텍스트를 기기 클립보드에 기록합니다. 이미지 공유를 선택하면 임시 PNG 파일을 생성하고 기기의 공유 메뉴를 표시합니다. 공유 메뉴 종료 후 앱의 임시 캡처를 해제합니다. 사용자가 저장하거나 다른 앱에 전달한 파일 및 클립보드 내용은 기기 또는 해당 앱의 정책에 따라 관리됩니다.

앱은 위치, 연락처, 마이크, 카메라에 접근하지 않습니다. 서버에 저장된 데이터가 없으므로 서버 데이터 삭제 절차나 회원 탈퇴 절차가 없습니다.

Privacy policy

Effective November 11, 2026. Visco Calculator does not collect or transmit personal information, account information, usage history or calculation inputs. It has no accounts, ads, analytics or backend. Earlier builds 1 and 2 process inputs in memory only. See the local storage and removal notice below.

Copying writes result text to the device clipboard. Image sharing creates a temporary PNG and opens the system share sheet; the app releases the temporary capture after sharing ends. Files you save or send and clipboard content are managed by the device or receiving app.

The app does not access location, contacts, microphone or camera. There is no server data or account to delete.

This static support site has no custom cookies, analytics or input forms. The hosting provider may process access information to operate its service. Calculation inputs are not sent to this site.

최근 설정 저장과 새 계산

Visco Calculator 1.0.0 빌드 3부터 최근 입력값, 목표 점도, 엔진 선택을 기기에 저장합니다. 1.0.1의 ‘새 계산’은 확인 후 동점도를 비우고 측정온도를 초기값 50°C로 되돌리며 목표 점도와 엔진 선택은 유지합니다. 설정까지 지우려면 기기의 앱 데이터 삭제 또는 앱 삭제 기능을 사용하세요. 앱 자체의 서버 전송은 없습니다. Android 앱은 백업을 사용하지 않으며 iOS의 기기 백업은 운영체제 설정에 따릅니다. 기존 빌드 1·2는 입력값을 저장하지 않습니다.

Since version 1.0.0 build 3, recent inputs, target viscosity and engine selection are stored on the device. In version 1.0.1, New calculation clears viscosity and resets measurement temperature to the initial 50°C after confirmation, while retaining the target and engine choice. To remove settings as well, use the device’s app data removal or app deletion feature. The app does not transmit these values to a server. Android app backup is disabled; iOS device backup follows operating system settings. Earlier builds 1 and 2 do not retain inputs.
